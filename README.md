# FitGram - 2-Day Recomp Tracker

A standalone, Instagram-dark-themed Progressive Web App (PWA) tailored for tracking a 2-day-per-week workout routine, daily calorie deficit, protein adherence, and body recomposition metrics.

## Files Included:
- `index.html`: Complete single-page application with responsive Instagram dark mode UI, Chart.js visualizations, and Tone.js audio cues.
- `manifest.json`: Web App Manifest enabling standalone iPhone Home Screen installation.
- `sw.js`: Service Worker supporting push notifications and offline caching.

## How to Run & Install on iPhone:
1. **Host for Free:** Upload these files to GitHub Pages, Vercel, Netlify, or run a local server (`python3 -m http.server 8000`).
2. **Open in Safari:** Navigate to your hosted URL on your iPhone.
3. **Add to Home Screen:** Tap the Safari **Share** icon and select **Add to Home Screen**.
4. **Enable Push:** Open FitGram from your home screen, tap the bell icon, and enable native iOS push notifications.
